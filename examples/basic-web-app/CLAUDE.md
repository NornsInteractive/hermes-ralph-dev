# 项目：basic-web-app

## 项目描述
这是一个面向小团队的任务管理 API 服务，提供用户登录、任务创建、任务分配和状态流转能力。
当前目标是实现认证和任务 CRUD 的第一版接口，并补齐基础测试。

## 技术栈
- 语言：TypeScript
- 框架：Node.js + Express
- 数据库：PostgreSQL
- 测试：Vitest + Supertest

## 目录结构
- `src/`：业务源码
- `docs/`：详细文档
- `tests/`：测试

## 开发规范
- 详细模块、表结构和接口定义全部以 `docs/` 为准
- 每次完成一个任务后更新 `docs/changelog/done.md`
- 如果当前仓库已启用 git，则每个完整任务结束后提交一次
- 提交前执行测试
