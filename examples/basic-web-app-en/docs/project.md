# Project overview

## Background
The team wants a lightweight internal API for managing work items. Team members should be able to log in, see assigned tasks, and update task status.

## Goals
- Provide reliable authentication
- Provide task CRUD and filtering
- Offer a REST API that web or third-party clients can consume

## Current task
The current development round focuses on the first version of the login and task management APIs, plus the corresponding tests.
