# basic-web-app example

This is a demonstration project skeleton that shows the kind of files a generic agent prepares for Ralph / Claude Code after receiving a development request.

Scenario:

- Project type: task management Web API
- Tech stack: Node.js, Express, PostgreSQL
- Current task: implement JWT login and task CRUD

These files are intended to demonstrate the generated structure and do not need to be runnable as-is.
