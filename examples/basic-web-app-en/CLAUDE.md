# Project: basic-web-app

## Project description
This is a task management API for small teams. It supports user login, task creation, task assignment, and task status updates.
The current goal is to implement the first version of authentication and task CRUD, then add the baseline tests.

## Tech stack
- Language: TypeScript
- Framework: Node.js + Express
- Database: PostgreSQL
- Testing: Vitest + Supertest

## Directory layout
- `src/`: application source code
- `docs/`: detailed documentation
- `tests/`: tests

## Development rules
- Module definitions, schema notes, and API contracts under `docs/` are the source of truth
- After completing each task, update `docs/changelog/done.md`
- If the repository already uses git, create one commit after each complete task
- Run tests before committing
